# StarTag

Homepage of StarTag, a Chrome extension for Facebook Marketplace in Texas: next to a car's asking
price it shows what cars like it actually sell for in Texas (the TxDMV Standard Presumptive Value,
built from Texas sales). https://celalertug.github.io/startag/

Questions and problems: [open an issue](https://github.com/celalertug/startag/issues).

The site is a single static page (`index.html`), served by GitHub Pages from the `main` branch.
`img/og.png` (1200×630, the link preview) is a screenshot of the page's hero.
