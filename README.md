# StarTag

Homepage of StarTag, a Chrome extension that shows the Texas Standard Presumptive Value (TxDMV) of
Facebook Marketplace vehicle listings, with similar variants: https://celalertug.github.io/startag/

Questions and problems: [open an issue](https://github.com/celalertug/startag/issues).

The site is a single static page (`index.html`), served by GitHub Pages from the `main` branch.
